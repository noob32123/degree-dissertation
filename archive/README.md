# Historical iteration archive

The active manuscript and experiment package remain in paper and md_cbad_dqn at the repository root.

history_before_current_2026-08-27 preserves materials that do not belong to the current release. Original workspace-relative paths are retained beneath the archive snapshot so files can be restored with an ordinary move.

Archived classes include:

- the pre-existing wasted history tree
- reviewer_revision and smoke result sets
- legacy checkpoints and root-level result summaries
- earlier manuscript sources and marked copies
- earlier peer-review and response rounds
- unused figure and conceptual-image iterations
- stale PDF duplicates, LaTeX auxiliaries and page renders
- temporary previews and Python bytecode caches

Nothing in this archive is required by paper/source.tex or by the current reviewer_revision_state_complete reporting and validation entry points.

ARCHIVE_FILE_INDEX.tsv lists every archived file with its snapshot-relative path, byte size and last-modified timestamp.

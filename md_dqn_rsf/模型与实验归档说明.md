# 模型与实验归档说明

## 1. 归档结论

论文当前使用的主实验和独立 RSF 两阶段实验均已重新运行并完成模型归档。

- 主实验：5 种学习策略 × 5 个独立模型种子，共 25 个模型，全部通过加载与前向推理检查。
- RSF 确认性实验：4 种 DQN 变体 × 10 个独立模型种子，共 40 个确认性模型，全部纳入统计，无种子剔除。
- RSF 两阶段目录中另有 7 个校准阶段模型。因此，该目录的独立验证报告共检查 47 个模型；其中真正用于最终确认性结论的是 `confirmatory` 子目录中的 40 个模型。
- 非学习基线通过确定性规则或解析式即时计算动作，不存在可保存的神经网络模型。

主实验中的学习策略共享同一套环境和配对外生轨迹。每个模型种子内部的 20 条测试轨迹先求均值，再把模型种子作为独立统计单位，避免把同一模型上的多条轨迹错误当成独立重复。

## 5. 检查点包含的内容

每个 `.pth` 文件不仅保存在线 Q 网络权重，还保存：

- 目标网络权重；
- 优化器状态；
- 完整的 `AgentConfig`；
- 训练步数和最终 epsilon；
- reset/flush 是否触发、损失指数移动平均和跳过更新数；
- 状态维数 21、动作维数 3、训练回合数、时间跨度和 PyTorch 版本。

因此，这些文件既可用于推理，也可用于检查训练配置和在相同代码版本上恢复训练状态。

## 6. 模型加载示例

在 `md_dqn_rsf` 目录运行：

```python
from pathlib import Path

import torch

from agent import QNetwork

checkpoint_path = Path(
    "outputs_archive_final_v1/models/standard_dqn_seed_003.pth"
)
device = torch.device("cuda:0" if torch.cuda.is_available() else "cpu")
payload = torch.load(checkpoint_path, map_location=device, weights_only=False)

model = QNetwork(payload["state_dim"], payload["action_dim"]).to(device)
model.load_state_dict(payload["online_state_dict"], strict=True)
model.eval()

# 实际推理时，state 必须由 environment.py 按训练时相同方式构造。
state = torch.zeros(1, payload["state_dim"], dtype=torch.float32, device=device)
with torch.no_grad():
    q_values = model(state)
    action = int(q_values.argmax(dim=1).item())

print(q_values, action)
```

## 7. 结果和论文表述边界

### 7.1 主实验

模型持久化重跑所得核心 CSV 与此前正式结果 `outputs_final_v2` 逐字节一致，说明新增保存逻辑没有改变随机序列、训练过程或评价结果。

主实验平均总成本包括：

| 策略 | 平均总成本 |
|---|---:|
| Standard DQN | 326.4534 |
| MD-DQN-RSF | 327.2038 |
| Immediate argmin | 395.5533 |

主实验支持“序列价值学习相对即时贪心策略具有明显优势”，但该实验本身不支持“RSF 一定优于普通 DQN”，因为其中完整 RSF 的均值略高于普通 DQN。

### 7.2 独立 RSF 确认性实验

确认性实验的种子级统计结果为：

| 策略 | 平均总成本 | 种子间 SD | 相对 Standard DQN 的均值变化 |
|---|---:|---:|---:|
| Standard DQN | 321.6487 | 7.2194 | — |
| DQN-R | 320.3556 | 6.5334 | -1.2930（改善 0.4020%） |
| DQN-RS | 320.4428 | 6.5360 | -1.2058（改善 0.3749%） |
| MD-DQN-RSF | 320.5163 | 6.7250 | -1.1324（改善 0.3521%） |

完整 MD-DQN-RSF 相对 Standard DQN 的配对 95% 区间为 `[-3.0944, 1.0017]`，跨越零。因此可以写成“完整 RSF 在均值上取得小幅改善”，但不能写成“完整 RSF 的优势稳定或已得到统计确认”。

DQN-R 的配对 95% 区间为 `[-2.4431, -0.2548]`，在本次预设确认性实验中未跨零。这说明 reset 单独机制显示出较一致的小幅收益；但 R+S 和完整 RSF 没有表现出随机制叠加而单调增强的证据。因此，消融实验更适合支持“reset 是主要有效成分，S/F 的增量贡献尚不确定”，不应声称三个组件都被独立证明有效。

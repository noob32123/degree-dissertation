# 状态补全轮审稿意见修改记录

本记录对应 2026-08-27 三份独立模拟审稿及其综合报告。数值项以状态补全后的 20 个模型种子结果为准；代码与数据归档标识由作者在投稿前填写。

## 状态补全后的叙事决策

状态补全结果不支持继续把 CBAD 作为统一优胜算法：CBAD 相对标准 DQN 的平均改善约为 0.45%--0.85%，完整的区间加 Holm 判据仅在五个耦合场景中的三个通过；CBAD 相对 uncentered full-action Q 和 immediate-advantage 的直接对比均未在任何场景满足完整判据。六种 DQN 目标在 nominal 场景的均值范围仅为 77.66--78.40，而它们与 MPC-4（90.83）、contextual bandit（101.00）和 myopic/heuristic/fixed policies 的差距更大。

因此，全文主线改为“DQN 及其目标变体在合成软约束卫星地面调度任务上的比较表现”。家族级结论先描述长时域 DQN 与 myopic、heuristic 和有限时域精确规划器的差异；CBAD 仅作为 centered full-action 变体参与家族内比较，不再承担独特优越性或机制识别主张。

## 通过论证重构处理的问题

| 意见 | 处理 | 保留边界 |
|---|---|---|
| R2-M1：与最接近全动作或模型辅助方法的区别不足 | 新增方法特征比较表，明确与 Dyna/局部模型加速、CAIAC、反事实信用分配和 Joint MDPs 的训练信号、模型用途与边界；将 novelty 限定为被评估的辅助损失及其调度实现 | 没有宣称模型使用、全信息反馈、反事实模拟、优势学习或中心化本身具有原创性 |
| R1-M3 / R2-M2 / R3-M2：合成目标、零能量和软约束不能证明可行调度 | 题目显式标注 synthetic soft-constrained；摘要、结果、讨论和结论反复区分复合成本改善与硬可行性/任务价值 | 不宣称飞行可用、安全、硬约束可行或工程效用；未新增 utility-weight 敏感性 |
| R2-M3 / R3-M1：缺少广泛竞争性基线和第二任务 | 将贡献限定为匹配 DQN 骨干及已实现精确有限时域规划器中的模拟器结果；列出未比较的增强值学习、可扩展优化器和卫星专用调度器 | 不宣称优于现代 RL、传统优化、运营调度系统或其他任务类别 |
| “counterfactual” 可能被误读为因果效应 | 首次出现后定义为同一当前状态下由模型评估的未执行动作一步结果 | 不作观测数据因果识别主张 |

- 在 Data and Code Availability 中填写真实、永久的代码与数据归档标识；当前保留醒目标记，不虚构 DOI。
- 若要恢复硬约束调度、飞行相关性或更广泛科学意义主张，需要新增受约束控制/动作屏蔽、任务效用权重敏感性、任务或系统外部验证、以及信息预算匹配的最近方法或有竞争力调度基线。本轮没有用措辞替代这些缺失证据。
